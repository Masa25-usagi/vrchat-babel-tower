# VRChat バベルの塔

発話を翻訳してOSC経由でVRChatのチャットへ送る試作。

ローカルで作成したツールの公開用ソースです。試作段階の機能も含みます。実際の利用記録、認証セッション、APIキー、個人用の配備設定は配布していません。

## セットアップ

Node.js 22.18以上を使用してください。

```sh
npm ci
```

`npm run dev`: `node server.js`

`npm run start`: `node server.js`

## 設定とデータ

外部サービスを使用する機能は、利用者自身のアカウントとAPIキーを設定してください。`.env.example`がある場合は`.env`へコピーして設定します。キーはサーバー側またはOSの安全な保存領域に置き、Gitへ追加しないでください。

デモには架空の入力を使用してください。生成された記録・録音・予定・健康データは利用者の環境だけに保存し、公開リポジトリへ追加しないでください。

## 確認

`npm start`でlocalhost:3000を開きます。初期状態は練習モードで、自動送信は無効です。入力・翻訳のWebSocketプレビューを合成テキストで確認しました。実VRChatへの送信、音声認識、外部翻訳APIは今回の公開準備では検証していません。
